## prayfile.github.io

Static GitHub Pages landing for pray and Prayfile at [pray.kisko.dev](https://pray.kisko.dev/).

Primary surfaces: `index.html` (presentation), `index.md` (Markdown mirror), `llms.txt` (LLM index), `DESIGN.md` (visual system), `assets/`.

Before changing landing UI, read `DESIGN.md`. Match chamber tokens and do-nots. Format follows Google Labs DESIGN.md; related catalog at https://getdesign.md/.

Keep HTML and Markdown examples aligned with the Prayfile destination DSL in [kiskolabs/pray](https://github.com/kiskolabs/pray) (`compose`, `tree`, `pray`, `file:`). Spec and CLI live upstream; this repo only publishes the public landing. Adopt prompt and full package catalog stay in `llms.txt` and amkisko/prayers, not on the HTML landing.
